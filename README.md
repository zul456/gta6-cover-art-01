Palmline Cover Studio turns any photo and a caption into GTA 6-style cover art: a multi-panel poster (split, grid or bands layouts) with a Vice City sunset or neon grade, a sun disc, grain and vignette, and bold outlined title lettering, exported as a PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. It runs entirely offline in the browser — photos never leave the machine. Each panel takes its own photo, with drag to position and scroll to zoom, and the title and subtitle are editable live.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
